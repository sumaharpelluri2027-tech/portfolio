# Photo & audio checklist

One list for everything the site can use. Tick items off as you send them. Each file has a fixed name, so it can be dropped in here and reused anywhere else later (LinkedIn, decks, other portfolios).

## How to send
- **Photos:** JPG or PNG, the largest you have. I crop, colour-match and convert to WebP.
- **Audio:** one clip per line, quiet room, phone held about 20 cm away, natural pace. MP3 or M4A, named exactly as the key (for example `story-1.mp3`).

## 5. Reusing these elsewhere
- Keep the same file names; I can drop the same set into another site, a deck, or a LinkedIn banner without renaming.
- With 3–5 minutes of clean recordings, a voice-cloning tool (for example ElevenLabs or Fish Audio) can generate any new line in your voice. Only do this with a tool and account you're comfortable with.
